A collection of beginner-friendly Python GUI projects built using Tkinter. These projects are designed to practice GUI development, handle user input, and implement basic functionality with Python.

# Tkinter
Tkinter is Python’s standard library for building graphical user interfaces (GUIs).
- GUI = anything you can click, type in, or interact with visually (windows, buttons, sliders).
- Tkinter stands for “Tk interface”, because it’s a wrapper around Tk, a powerful GUI toolkit written in C.
Essentially, Tkinter lets Python speak to Tk, which then tells your computer to draw windows and widgets.
